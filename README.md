# homebrew-tap

Personal tap.

```sh
brew install mrgawrys/tap/docket
```

`docket` — https://github.com/mrgawrys/docket — pre-runs Claude Code's
`/code-review` on PRs awaiting your review.

The formula goes live with docket's first tagged release: until its two
sha256 placeholders are filled from that release's `SHA256SUMS`
(see docket's `packaging/README.md`), `brew install` will refuse it.
